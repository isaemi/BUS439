# Brand assets

Put the official UBC logo here as `ubc-logo.svg` (or `ubc-logo.png`) and it appears in the app header.

- Get the file from UBC Brand (brand.ubc.ca) or from SHW communications; do not redraw, recolour or crop it.
- For the dark header bar, use the reverse (white) version of the logo.
- Ask SHW before using the logo in anything shared outside the project team.

Without a logo file, the header shows the university name as plain text.
