# Database schema

Generated by `python -m shw_analytics.schema --markdown` from the live database.

## Relationships

- `ratings.response_id -> responses.response_id (many ratings per response)`
- `comments.response_id -> responses.response_id (zero or more comments per response)`
- `response_faculty.response_id -> responses.response_id (one row per selected faculty)`
- `response_disability.response_id -> responses.response_id (one row per selected disability)`
- `response_multi.response_id -> responses.response_id (one row per selected option)`
- `ratings.item_code -> items.item_code (each rating is for one item)`

## Views

- `ratings_demo`: ratings joined to responses: every rating with the respondent's demographics. Use this for most questions; no join needed.

## `comments` (950 rows)

Open-text comments, scrubbed of names, emails and numbers. Not reachable from SQL. Key: response_id + question_code.

| Column | Type | Meaning |
|---|---|---|
| `response_id` | VARCHAR | Links to responses |
| `service` | VARCHAR | Service the comment is about |
| `question_code` | VARCHAR | Qualtrics question the comment answers |
| `text` | VARCHAR | Scrubbed comment text |

## `data_quality` (11 rows)

Problems found in the Qualtrics export at the last rebuild.

| Column | Type | Meaning |
|---|---|---|
| `issue` | VARCHAR | Kind of problem |
| `detail` | VARCHAR | What was found |
| `count` | DOUBLE | How many rows |

## `items` (47 rows)

Catalogue of survey items per service. Key: item_code.

| Column | Type | Meaning |
|---|---|---|
| `service` | VARCHAR | Service the item belongs to |
| `block` | VARCHAR | Qualtrics question block, e.g. CS1 |
| `item_code` | VARCHAR | Qualtrics question code |
| `item_text` | VARCHAR | Wording of the item |
| `duplicate_of` | VARCHAR | Item code this one repeats, if the same wording appears twice |

## `ratings` (4,407 rows)

One row per Likert answer (response x survey item), score 1-5. Key: response_id + item_code.

| Column | Type | Meaning |
|---|---|---|
| `response_id` | VARCHAR | Links to responses |
| `service` | VARCHAR | Service the item belongs to |
| `item_code` | VARCHAR | Qualtrics question code, e.g. CS1_3 |
| `score` | BIGINT | 1 = strongly disagree ... 5 = strongly agree |
| `agree` | BOOLEAN | True if score is 4 or 5 |
| `item_text` | VARCHAR | Wording of the survey item |

## `response_disability` (4,144 rows)

One row per disability category a respondent selected (multi-select). Key: response_id + disability.

| Column | Type | Meaning |
|---|---|---|
| `response_id` | VARCHAR | Links to responses |
| `disability` | VARCHAR | Disability category |

## `response_faculty` (9,223 rows)

One row per faculty a respondent selected (multi-select). Key: response_id + faculty.

| Column | Type | Meaning |
|---|---|---|
| `response_id` | VARCHAR | Links to responses |
| `faculty` | VARCHAR | Faculty name, e.g. Arts |

## `response_multi` (919 rows)

One row per option selected in other multi-select questions. Key: response_id + question + value.

| Column | Type | Meaning |
|---|---|---|
| `response_id` | VARCHAR | Links to responses |
| `question` | VARCHAR | Which question, e.g. racial_background |
| `value` | VARCHAR | Selected option code |

## `responses` (695 rows)

One row per survey response: the service used, follow-up answers and demographics. Key: response_id.

| Column | Type | Meaning |
|---|---|---|
| `response_id` | VARCHAR | Qualtrics ResponseId; links every other table |
| `recorded_at` | TIMESTAMP | When the response was recorded |
| `channel` | VARCHAR | Qualtrics distribution channel (anonymous = real link, test, preview) |
| `finished` | BOOLEAN | True if the respondent reached the end of the survey |
| `progress` | BIGINT | Percent of the survey completed |
| `service_code` | BIGINT | Code of the service the respondent rated (survey question Int1) |
| `service` | VARCHAR | Service key, e.g. medical, counselling |
| `service_name` | VARCHAR | Service display name |
| `wa_time_since_first_booking` | VARCHAR | Survey question WA2 (coded answer) |
| `wa_fell_short` | VARCHAR | Survey question WA3 (coded answer) |
| `med_wait_time` | VARCHAR | Survey question MED2 (coded answer) |
| `med_preferred_format` | VARCHAR | Survey question MED3 (coded answer) |
| `med_fell_short` | VARCHAR | Survey question MED4 (coded answer) |
| `cs_wait_time` | VARCHAR | Survey question CS2 (coded answer) |
| `cs_fell_short` | VARCHAR | Survey question CS3 (coded answer) |
| `academic_level` | VARCHAR | Survey question D1 (coded answer) |
| `new_to_ubc` | VARCHAR | Survey question D2 (coded answer) |
| `year_of_study` | VARCHAR | Survey question D3 (coded answer) |
| `enrollment_status` | VARCHAR | Survey question D4 (coded answer) |
| `intl_or_domestic` | VARCHAR | Survey question D7 (equity dimension; coded answer) |
| `living_arrangement` | VARCHAR | Survey question D8 (coded answer) |
| `indigenous` | VARCHAR | Survey question D9 (equity dimension; coded answer) |
| `racialized` | VARCHAR | Survey question D10 (equity dimension; coded answer) |
| `racial_background` | VARCHAR | Survey question D11 (raw comma list; one row per option in response_multi) |
| `first_generation` | VARCHAR | Survey question D12 (equity dimension; coded answer) |
| `gender` | VARCHAR | Survey question D13 (equity dimension; coded answer) |
| `trans_experience` | VARCHAR | Survey question D14 (equity dimension; coded answer) |
| `identity_d15` | VARCHAR | Survey question D15 (raw comma list; one row per option in response_multi) |
| `birth_year` | BIGINT | Year of birth; blank if missing or invalid |
| `disability_any` | VARCHAR | yes if any disability category was selected, no if only 'None' |
